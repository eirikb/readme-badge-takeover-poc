README badge takeover

A badge is an image request to a server, dressed up as a fact. Here is how far that goes.

☞ If you got here by clicking a "README", that is the point.
You clicked what looked like a project's documentation — links, install command, security advisory and all — and it was a single image served from a third-party badge URL, wrapped in one link that sent you here. Not one byte of it lives in the repository you were looking at.
