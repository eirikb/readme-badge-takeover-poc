README badge takeover

A badge is an image request to a server, dressed up as a fact. Here is how far that goes.

☞ If you got here by clicking something that looked like a README, that is the point.
What you clicked was a single image served from a third-party URL, wrapped in one link. Not one byte of it lived in the repository you were reading.

The seamless one — an image that reads as README text

Below, the first line is real browser text. Everything from “Installation” down is a single SVG image served from this server. Same font, same size, same theme (it tracks light/dark on its own). Can you see the seam?

awesome-project is a fast, dependency-free toolkit. The quickest way to get going is below.

That is the trap: on GitHub an embedded image renders in secure static mode (no script, no tracking), but nothing stops it from looking like the prose around it and saying whatever the host wants it to say. Wrap it in a markdown link and the whole thing becomes clickable.
